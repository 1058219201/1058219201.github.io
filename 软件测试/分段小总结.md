## select的使用

where

```mysql
SELECT 列名 FROM 表名 WHERE 条件;

实例：
从 users 表中查询年龄大于 18 的用户：
SELECT name, age FROM users WHERE age > 18;
```

比较运算符：

![image-20260130154224044](C:\Users\asus\AppData\Roaming\Typora\typora-user-images\image-20260130154224044.png)

逻辑运算符：

1. **`AND`**：所有条件必须同时满足

   ```mysql
   SELECT * FROM products WHERE price > 50 AND stock > 0;
   ```

2. **`OR`**：只要有一个条件满足即可

   ```mysql
   SELECT * FROM users WHERE city = '北京' OR city = '上海';
   ```

3. **`NOT`**：取反条件

   ```mysql
   SELECT * FROM orders WHERE NOT status = '已取消';
   ```

模糊查询(LIKE)：

- **`%`**：匹配任意长度的字符（包括 0 个）
- **`_`**：匹配单个字符

```mysql
-- 查询名字以'张'开头的用户
SELECT * FROM users WHERE name LIKE '张%';

-- 查询名字第二个字是'小'的用户
SELECT * FROM users WHERE name LIKE '_小%';
```

范围查询：

- **`BETWEEN ... AND ...`**：在某个连续范围内的值

```mysql
SELECT * FROM products WHERE price BETWEEN 100 AND 200;
```

- **`IN`**：在某个离散集合中

```mysql
SELECT * FROM users WHERE city IN ('北京', '上海', '广州');
```

空判断：

**判断字段值是否为空，注意不能用 `=`，必须用 `IS NULL` 或 `IS NOT NULL`。**

```mysql
-- 查询没有填写邮箱的用户
SELECT * FROM users WHERE email IS NULL;

-- 查询已经填写邮箱的用户
SELECT * FROM users WHERE email IS NOT NULL;
```
